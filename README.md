# SalesPulse - Sales Analytics Dashboard

A modern, responsive, and standalone single-page Sales Analytics Dashboard built with vanilla HTML, CSS, and JavaScript.

## Highlights
- **100% Client-Side**: No backend required. Uses HTML5 Web Storage (`localStorage`) for real-time data persistence.
- **Strict Clean CSS**: Formatted without CSS variables for maximum compatibility.
- **Key Performance Indicators (KPIs)**: Total Revenue, Total Orders & Units Sold, Average Order Value (AOV), and Estimated Gross Profit.
- **Interactive Visualizations**: Revenue dynamics timeline, category donut breakdown, and sales channel distribution (powered by Chart.js with high-fidelity native HTML5 Canvas fallback).
- **Target Tracking**: Real-time monthly sales quota progress meter and top revenue-contributing products.
- **Full Sales Ledger**:
  - Paginated transaction records with sortable columns.
  - Add and Edit transaction modal dialogs.
  - Multi-select batch deletion.
  - Instant live keyword search and multi-criteria filters.
  - One-click CSV report export.

## Getting Started
Simply clone or download this repository and open `index.html` in any modern web browser.
